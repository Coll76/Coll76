## Hey, I'm Collins

Backend developer based in Nairobi, Kenya.

From a young age I have always loved seeing things come to life. It started with building toys out of sticks like the other kids, except I was never satisfied with just building them. I would scratch my head figuring out how to make mine better. That curiosity never left. When I got the chance I became a backend developer because it lets me do exactly that, design systems, optimize how they work, and watch them hold up under real users. That part never gets old.
